# kvm-manager v1.1.2 版本更新日志

**发布日期**: 2026-06-08  
**提交数量**: 1 次提交  
**版本类型**: 修订优化版本

---

## 📋 版本概述

v1.1.2 聚焦 Agent 接入保存体验和总览虚拟机统计口径优化。新增 Agent 保存成功后不再等待首次 full 同步完成，而是立即释放保存按钮并在后台同步宿主机、虚拟机和快照运行态；总览页的虚拟机运行 / 总数、状态分布、vCPU 已分配和最近虚拟机列表统一排除已标记模板，避免模板影响真实虚拟机资源视图。

---

## ✨ 新增特性

- Agent 保存成功后新增后台同步提示，保存动作完成后立即提示“已保存，正在后台同步”。
- 后台同步完成或失败时继续通过 toast 提示结果，并按原有 SSE 链路刷新页面数据。

---

## 🐛 Bug 修复

- 修复总览页虚拟机运行 / 总数未排除模板的问题。
- 修复总览页虚拟机状态分布、vCPU 已分配和最近虚拟机列表与虚拟机页面模板拆分口径不一致的问题。

---

## 🚀 性能优化

- 优化新增 Agent 保存交互链路，保存成功后不再阻塞等待首次 full 同步完成，降低用户感知等待时间。

---

## 🔧 重构优化

- 抽取总览虚拟机统计逻辑，统一处理非模板虚拟机数量、状态分布、vCPU 已分配和最近虚拟机列表。
- 保留 Agent 同步的原有 full 同步能力，只将首次同步从保存按钮等待链路中解耦为后台执行。

---

## 📚 文档更新

- 更新 README 刷新机制和 API 文档说明，补充 Agent 保存后后台同步行为。
- 更新 README、Swagger/OpenAPI 文档，说明总览虚拟机统计排除已标记模板。
- 更新 `docs/frontend-refresh-functions.md`，补充新增 Agent 保存后的后台同步刷新链路。
- 更新 `docs/host-info-collection.md`，补充总览页非模板虚拟机统计口径。

---

## 🔄 API 变更

- `GET /api/dashboard/summary` 的虚拟机统计口径调整为排除已标记模板。
- 接口字段结构不变，`totalVMs`、`runningVMs`、`stoppedVMs`、`pausedVMs`、`errorVMs`、`usedVCPUs` 和 `recentVMs` 的数值语义更新为非模板虚拟机口径。

---

## 📊 数据库变更

- 本版本不新增数据库表结构或迁移脚本。
- 虚拟机模板标记仍使用既有 `vm_template_marks` 数据。

---

## 🔄 升级说明

升级前请先备份 PostgreSQL 和 Redis 数据。

升级后，总览页虚拟机统计会自动排除已标记模板。如果此前依赖总览页统计所有 libvirt domain 数量，请改用虚拟机页面的“虚拟机 / 模板”切换视图分别查看真实虚拟机与模板数量。

新增 Agent 保存后会立即返回保存结果，首次 full 同步改为后台执行。同步期间可在宿主机页继续查看 Agent 状态，后台同步完成后页面会通过原有 SSE 刷新链路更新宿主机、虚拟机和快照数据。
