# kvm-manager v1.1.5 版本更新日志

**发布日期**: 2026-06-09  
**提交数量**: 2 次提交  
**版本类型**: 性能优化版本

---

## 📋 版本概述

v1.1.5 聚焦存储池页面在卷数量较多场景下的加载性能和展示准确性。存储池列表页不再为了卡片卷数量读取完整卷详情并逐卷执行 `qemu-img info`，改为基于 `virsh vol-list <pool> --details` 做轻量计数，并按真实 `Type` 排除 `dir` 目录条目。存储池详情页继续保留完整卷详情读取、格式识别、创建、上传、克隆和删除逻辑，同时过滤目录型条目，避免目录被当作可操作卷或光盘镜像展示。

---

## ✨ 新增特性

- 存储池详情列表新增目录型条目过滤，`Type=dir` 的 libvirt 卷不再展示为卷或光盘镜像。
- 存储池列表卷数量按 `virsh vol-list --details` 的真实 `Type` 过滤目录条目，列表数量与详情列表口径保持一致。

---

## 🐛 Bug 修复

- 修复旧版 virsh 不支持 `vol-list --name` 时，存储池卡片卷数量可能显示为 `0` 的问题。
- 修复目录型条目出现在存储池详情卷列表中，容易被误认为可克隆、可删除镜像卷的问题。

---

## 🚀 性能优化

- 存储池列表页卷数量改为轻量计数，不再触发完整卷详情解析。
- 存储池列表页不再为每个卷执行 `qemu-img info -U --output=json`，减少卷数量较多时的加载耗时。
- 保留 `pool-refresh` 和 `vol-list --details` 以确保卷数量较新，同时避免进入详情前执行格式探测。

---

## 🔧 重构优化

- Agent 存储池采集拆分轻量卷数量统计和完整卷详情解析两个路径。
- 新增存储池卷计数和目录型卷过滤测试，覆盖 `dir` 类型排除、旧版 virsh 兼容和列表页不触发 `qemu-img` 的行为。

---

## 📚 文档更新

- 更新 `docs/frontend-refresh-functions.md`，说明存储池列表页卷数量轻量计数和目录过滤规则。
- 更新 `docs/vm-info-collection.md`，说明存储池列表与详情的 `virsh vol-list --details` 采集边界，以及 `dir` 类型过滤策略。

---

## 🔄 API 变更

- 接口路径和响应结构不变。
- `/api/storage-pools/{agentId}` 的 `volumeCount` 统计口径调整为排除 `dir` 类型目录条目。
- `/api/storage-pools/{agentId}/volumes/{pool}` 返回的卷列表不再包含 `Type=dir` 的目录条目。

---

## 📊 数据库变更

- 本版本不新增数据库表结构或迁移脚本。

---

## 🔄 升级说明

升级前请先备份 PostgreSQL 和 Redis 数据。

本版本不需要执行数据库迁移。升级 Agent 后，存储池页面会自动使用新的卷数量统计和详情过滤逻辑。若某些目录型条目此前出现在详情列表中，升级后会被隐藏；真实镜像卷、ISO 文件和块设备卷仍会继续展示。
