# kvm-manager v1.1.6 版本更新日志

---

## 📋 版本概述

v1.1.6 聚焦平台运维日志保留策略和前端格式化覆盖。后端新增 `LOG_RETENTION_DAYS` 环境变量，统一控制任务、审计和告警日志按 `created_at` 创建时间自动清理，默认保留 30 天，并支持设为 `0` 关闭自动清理。前端格式化脚本补充 `tsx` 文件匹配范围，确保 React 页面和组件文件也纳入统一格式化检查。本版本同时修正文档中的环境变量、项目结构和部署示例说明。

---

## ✨ 新增特性

- 新增后端 `LOG_RETENTION_DAYS` 环境变量，默认 `30` 天。
- 后端启动时新增日志保留清理协程，每 24 小时清理一次过期任务、审计和告警日志。
- 任务、审计和告警三类记录统一按 `created_at` 创建时间判断是否超过保留期。
- 支持将 `LOG_RETENTION_DAYS` 设置为 `0` 或负数来关闭日志自动清理。

---

- 新增独立的仓储保留清理文件，避免继续扩大通用仓储文件。

- 新增日志保留配置读取测试和清理 SQL 语义测试，覆盖默认值、自定义值和按 `created_at` 清理的约束。

## 🔄 升级说明

升级前请先备份 PostgreSQL 和 Redis 数据。

升级后后端默认保留最近 30 天的任务、审计和告警日志。若需要更长保留周期，请在后端或部署环境变量中设置：

```bash
LOG_RETENTION_DAYS=90
```

如需关闭自动清理，可设置：

```bash
LOG_RETENTION_DAYS=0
```

本版本不需要执行数据库迁移。
