# kvm-manager v1.0.0 版本更新日志

**发布日期**: 2026-06-07  
**提交数量**: 3 次提交  
**版本类型**: 首个正式版本

---

## 📋 版本概述

v1.0.0 是 kvm-manager 的首个正式版本，完成了 KVM 管理控制台、宿主机 Agent、前端运维界面、运行态缓存、指标趋势、权限体系、任务审计告警和 Docker 发布链路的基础闭环。

---

## ✨ 新增特性

- 新增 KVM Agent 管理链路，支持登记、连接测试、同步和宿主机资源采集。
- 新增虚拟机列表、创建、编辑、克隆、迁移、启停、暂停、重启、删除、强制删除和控制台代理能力。
- 新增存储池、存储卷、网络池、宿主机接口和快照管理能力。
- 新增 Redis 运行态缓存、SSE 实时刷新、fast/full 后台同步和指标样本落库。
- 新增虚拟机与宿主机监控趋势、磁盘 I/O、网络吞吐和资源使用率展示。
- 新增 RBAC 角色权限体系，内置 admin、operator、viewer 角色和权限补齐规则。
- 新增任务、审计日志、通知中心和告警中心。
- 新增通知媒介配置，支持邮件、飞书、企业微信、钉钉和 Webhook。
- 新增自定义告警通知模板、通知消息类型和告警通知投递记录。
- 新增账号修改密码、忘记密码验证码重置和系统基础配置。
- 新增 Docker Compose 快速部署说明和主控台 Docker 镜像发布流水线。
- 新增 Backend 与 Agent 发布二进制交叉编译产物。

---

## 🐛 Bug 修复

- 修复发布流水线中 Backend 构建入口路径不一致的问题，统一使用 `cmd/server/main.go`。
- 修正 Release 文案中的项目名称，避免沿用旧项目标题。
- 修正 Docker Compose 默认镜像地址，改为阿里云镜像仓库地址。

---

## 🚀 性能优化

- 引入 Redis 运行态缓存，减少高频页面读取对 Agent 实时采集的压力。
- 使用 fast/full 分层刷新策略，将轻量状态同步与深度详情采集拆分执行。
- 增加指标 Stream 写入和趋势查询，支持宿主机与虚拟机监控数据持续沉淀。
- 增加定时保留策略和指标汇总能力，控制历史样本存储成本。

---

## 🔧 重构优化

- 后端按 `api/router`、`internal/service`、`internal/repository`、`pkg` 分层组织。
- Agent 按路由、配置、安全鉴权和 KVM/libvirt 能力模块拆分。
- 前端按 feature-first 组织页面、组件、工具函数和跨域基础能力。
- 通知设置拆分为独立面板和表单基础组件，降低设置页复杂度。
- 抽象 SelectMenu、Tooltip、弹窗框架、任务 toast 和刷新事件等通用前端能力。

## 🔄 升级说明

这是首个正式版本，新部署环境可直接按 README 的本地开发或 Docker Compose 部署说明初始化。

已有测试环境升级时，请先备份 PostgreSQL 和 Redis 数据，再启动后端让迁移脚本自动执行。生产环境应固定配置 `JWT_SECRET`、数据库密码、Redis 密码和 Agent Token。
