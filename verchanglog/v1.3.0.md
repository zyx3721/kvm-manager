## 📋 版本概述

本版本对企微扫码登录进行重构并对齐统一认证中心回调链路:直连模式改用企微官方 JS-SDK 登录面板,授权码经 JS 回调返回、面板不发生页面导航;统一认证中心 `callback_path` 调整为 `/login`,认证中心顶层回跳后由登录页以票据调用后端接口换取会话。两种模式统一「正在处理企业微信授权,请稍候…」过渡视图与面板尺寸,并跳过回跳时的品牌启动页。同时修复扫码后跳回登录界面无法进入的问题。

---

## ✨ 新增特性

- **企微扫码直连改用官方登录面板**：引入 `@wecom/jssdk`（动态 import 按需加载），直连模式渲染 `createWWLoginPanel` 官方登录面板（`redirect_type=callback`），扫码确认后授权码经回调返回并与签发 state 一并提交登录接口，面板不发生任何页面导航
- **统一认证中心回调链路对齐**：认证中心 `callback_path` 调整为 `/login`，登录页在认证中心顶层回跳 `/login?ticket` 后以票据调用 `POST /api/auth/wecom/sso/callback` 换取会话
- **登录页支持内嵌二维码渲染**：登录方式选择企业微信后页面内直接渲染扫码面板，全程不离开登录页
- **会话过期提示与登出清理顺序优化**：会话过期跳转登录页时明确提示重新登录

---

## 🐛 Bug 修复

- **扫码后跳回登录界面无法进入**：原后端 302 fragment 回传链路在顶层回跳时凭据无人消费，改为前端持凭据调用 POST 接口换会话后链路闭合
- **企微登录失败改为全屏错误卡片**：失败信息与「返回登录」入口统一在全屏过渡卡片展示，并跳过回跳时的品牌启动页
- **会话过期提示重复弹出**：仅在真实会话失效时弹出一次过期提示
- **未绑定账号提示文案优化**：「该企业微信账号尚未绑定系统用户」场景的提示更清晰

---

## 🚀 性能优化

- 企微官方 JS-SDK 改为动态 import，仅直连模式按需加载，登录页首屏不承担 SDK 体积

## 🔧 重构优化

- **直连面板尺寸与统一认证中心内嵌视图对齐**：面板宽度整卡、高度 380px，两种认证模式切换时登录卡片高度保持稳定；压缩面板内部留白使卡片高度接近本地账号模式
- **删除整页跳转降级链路**：兜底卡片、刷新重挂、「扫码异常？使用跳转方式登录」入口全部移除，authorize 失败在面板区域展示提示

## 🔄 API 变更

- 新增 `POST /api/auth/wecom/callback`：内嵌扫码直连登录，body `{code, state}`，成功返回会话 JSON
- 新增 `POST /api/auth/wecom/sso/callback`：内嵌扫码统一认证中心登录，body `{ticket}`，成功返回会话 JSON
- `GET /api/auth/wecom/authorize` 的 embed 响应新增直连模式 `state` 字段
- `GET /api/auth/wecom/sso/callback`（302 版）保留兼容既有整页回跳链路

---

## 📊 数据库变更

本版本无数据库 schema 变更；`auth_states` 表既有一次性票据机制保持不变，无数据迁移。

---

## 🔄 升级说明

- 直接替换二进制或更新镜像即可，无迁移脚本，无需手工执行 SQL
- **需要在统一认证中心（wecom-auth-center）侧将本应用的 `callback_path` 由 `/api/auth/wecom/sso/callback` 改为 `/login` 并重启认证中心**，否则 SSO 登录仍走旧 302 链路
- 企微管理后台的可信域名、可信 IP 配置保持不变
