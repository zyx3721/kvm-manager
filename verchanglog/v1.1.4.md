# kvm-manager v1.1.4 版本更新日志

**发布日期**: 2026-06-08  
**提交数量**: 3 次提交  
**版本类型**: 修订增强版本

---

## 📋 版本概述

v1.1.4 聚焦 Agent 采集在不同宿主机环境下的稳定性。Agent 外部命令统一使用 C locale，避免中文系统区域设置导致 `virsh` 状态、表头和解析结果不稳定；Agent 单命令默认超时从 8 秒调整为 30 秒，并新增后端 fast/full 同步 HTTP 超时配置，便于慢宿主机按需放宽采集窗口。本版本还修复了 `virt-df --csv` 新格式下全量刷新无法按 VM 匹配磁盘使用量的问题，减少 full 刷新时不必要的单 VM 兜底采集。

---

## ✨ 新增特性

- 新增 `RUNTIME_SYNC_FAST_TIMEOUT_SECONDS`，用于配置后端等待单个 Agent fast 同步返回的 HTTP 超时。
- 新增 `RUNTIME_SYNC_FULL_TIMEOUT_SECONDS`，用于配置后端等待单个 Agent full 同步和单台 VM full 刷新的 HTTP 超时。
- Agent 外部命令统一注入 `LC_ALL=C`、`LANG=C`、`LANGUAGE=C`，降低本地化输出对采集解析的影响。

---

## 🐛 Bug 修复

- 修复中文环境下 `virsh domstate` 返回 `运行中` 时虚拟机状态可能被识别为 `unknown` 的问题。
- 修复全量刷新中 `virt-df --csv` 输出 `VirtualMachine,Filesystem` 两列格式时，无法按 VM 名称匹配磁盘使用量的问题。
- 修复全局 `virt-df --csv` 复用失败后可能频繁出现 `collect guest filesystem usage list returned no matching filesystems` warning 的问题。

---

## 🚀 性能优化

- full 列表采集按 `VirtualMachine` 列复用全局 `virt-df --csv` 结果，减少每台 VM 额外执行 `virt-df --csv -d <vm>` 的概率。
- Agent 单命令默认超时调整为 30 秒，降低 libguestfs、磁盘 I/O 较慢时过早超时导致重复采集或临时目录残留的概率。

---

## 🔧 重构优化

- 后端实时同步服务新增 `Options` 配置入口，fast/full 同步超时由配置层传入，保留旧构造函数默认值兼容测试和内部调用。
- Agent `virt-df` CSV 解析改为明确读取 `VirtualMachine`、`Filesystem` 和 `Used` 三列，不再依赖旧的 `vm:/dev/xxx` 冒号格式。
- 补充 Agent 配置默认超时、命令环境和 `virt-df` 新格式解析的单元测试。

## 🔄 升级说明

升级前请先备份 PostgreSQL 和 Redis 数据。

升级后，如果宿主机 full 刷新仍因单个 Agent 响应较慢而出现“Agent 连接超时”，可在后端 `.env` 中调大：

```env
RUNTIME_SYNC_FULL_TIMEOUT_SECONDS=120
```

如果宿主机上 libguestfs 或磁盘探测仍较慢，可继续在 Agent `.env` 中调大：

```env
COMMAND_TIMEOUT_SECONDS=60
```

调整后需要重启对应后端或 Agent 服务生效。
